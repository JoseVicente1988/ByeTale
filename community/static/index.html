El proyecto real

ByeTale hoy

La comunidad se construye alrededor del juego que ya existe en el repositorio, no de una idea abstracta.

Universo

Godspire Citadel

El repositorio ya incluye recursos de entorno para Godspire Citadel y personajes como Player Character, Skeleton y Slime. La web debe funcionar como la ventana pública de ese mundo.

Núcleo

Arquitectura multijugador

Godot y ENet forman el núcleo de red. El proyecto contiene autenticación, estado de jugador, sincronización y persistencia.
